audiofy

Talk to your coding agent from any app.

Connecting…
  • Click the button (or press Space) to start talking, click again to send.
  • Hands-free: just talk, any time. A pause of about 2.5 seconds sends it. If the agent is busy, it gets your message as soon as it next listens. The mic closes while the agent speaks so it never hears itself.
  • Green pulse: the agent is waiting for you. Click while it's speaking to skip.
  • Pop out keeps the button floating above other windows (Chrome / Edge / Brave).
  • Global shortcut: bind your OS keyboard shortcut to audiofy ptt.
